App 侧 hilog（tag `LUTSA`）只记录感知事件、不记录释放动作：

```
20:11:36 BACKGROUND → 20:12:08 FOREGROUND → 20:12:52 BACKGROUND → 20:13:24 FOREGROUND → 20:14:10 BACKGROUND
```

**口径说明（如实记录）**：真机上「应用主动释放」与「系统回收 mmap 权重页 / 进程冻结」**无法分离**——
应用未输出释放动作日志，`hidumper` 也不给按映射拆分的明细。因此：
- 模拟器（OpenHarmony）上的 A/B（调度开 1370→71 MB；关 ≈1356 MB 不变）是**干净因果证据**（见 `14-对比试验原始数据.md`）；
- 真机数据只支持现象级结论：「切后台确实把约 0.68 GB 归还，回前台无需重载」。

> 采集：`hilog | grep LUTSA` 抓事件 + `hidumper --mem` 读 Pss；`uinput -K -d 1 -u 1`（HOME）切后台、`aa start` 回前台。
